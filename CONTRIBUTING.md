# Contributing

Thank you for your interest in contributing to Vpnifi.

## Development Setup

1. Fork the repository.
2. Create a new feature branch from `develop`.
3. Create a virtual environment.
4. Install the project dependencies.
5. Run the bot locally and verify your changes.

## Branch Naming

- feature/<feature-name>
- fix/<bug-name>
- refactor/<topic>
- docs/<topic>

Examples:

- feature/payment-system
- fix/order-service
- docs/readme

## Commit Messages

Use clear, descriptive commit messages.

Examples:

- feat: add payment workflow
- fix: resolve order creation bug
- refactor: move database logic to service layer
- docs: update README

## Pull Requests

Before opening a Pull Request:

- Ensure the project runs without errors.
- Keep changes focused on a single feature or fix.
- Update documentation if necessary.
- Verify that sensitive information such as `.env` is not committed.

Thank you for helping improve the project.
